# Model rental underwriting

Use for an explicit rental scenario or a verified template consumed by site search.
Read the [execution reference](references/runbook.md) before running the module.
Use fresh local runs/ destinations; preserve completed packages and source bytes.

Collect the proposed program, price basis, complete categorized capital budget,
income and expense streams with escalation/expiry, reserve treatment, financing
limits and source statuses. Missing inputs stay missing; do not turn the supplied
illustrative scenarios into market estimates or agency-approved programs.

The module uses Decimal arithmetic and a transparent annual cash waterfall.
Distinguish scenario homes, gross area, zoning area, tenant payments, operating
support, capital sources and debt. Proposed or modeled financing is not committed.
Source links and byte hashes do not establish correct professional interpretation.

Verify the package before a downstream handoff. Return the development budget,
loan-sizing constraints, unallocated capital, annual coverage/cash-flow failures,
source vintages, assumptions and unresolved work. Passing a selected ratio is not
a feasibility finding. Homeownership/co-op buyer finance needs a separate method.
