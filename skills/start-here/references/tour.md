# Offline first-result tour

Use only when the user wants a general introduction. Complete [editable setup](../../../docs/guides/setup.md)
first. After setup, replay needs no housing inputs, API keys, image provider or
network. Work from the repository root with Python 3.11+. If the checkout is missing:

```sh
git clone https://github.com/ptmr-gnai/open-housing-toolkit.git
cd open-housing-toolkit
```

After following setup in that checkout, run the [shared script](../../../scripts/first_run.py):

```sh
python scripts/first_run.py --out runs/my-first-run
```

Choose a fresh directory. The script builds and verifies cached parcel evidence →
area recipe → explicitly supplied illustrative housing offers → RER preparation.
A failure retains logs and stops later steps; no completed index is written.
On success, read the output README.md, then rer/packet.html, the separate program
drafts and coverage. Follow individual claims into the long evidence packets.
Read a selected leaf skill only when explaining or changing that module.

Explain the important handoff boundaries:

- 34 home-equivalents are an area quotient, not feasible homes.
- The 24/36-home offers are independent assumptions, not derived from that quotient.
- 16/8 homes meet a hypothetical lower-income cost-and-bedroom test; eligibility,
  delivery and the best program are not determined.
- RER drafts remain incomplete. Missing/interpretation-needed slots stay visible.
- Earlier "queried" wording refers to retained collection. The preparation date is
  supplied sample metadata, not automatically the execution date.
- Geometry and images were not generated by this tour.

GitHub shows HTML source; open local HTML or read Markdown. If execution is
unavailable, offer the committed examples and explicitly state that nothing ran.
