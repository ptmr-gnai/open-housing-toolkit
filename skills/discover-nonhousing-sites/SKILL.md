# Discover nonhousing sites

Use this as the first area-discovery route. Auto and parking lots are examples,
not required site types. Discovery requires geography and a question, without an
assumed FAR, extra-capacity threshold, financial model or private-only mission.
For a selected Bronx lot, use [housing-investigation](../housing-investigation/SKILL.md).

Read [the execution reference](references/runbook.md) when running the module.
Return the complete current-use dispositions, nonhousing zoning-path counts,
review lanes, examples and unresolved questions. Housing-recorded and ambiguous
records remain visible; do not equate zero apartments with no occupants.

General-use paths distinguish residential use permitted in principle, a rezoning
path, and special/unresolved review. Reconcile all recorded districts and special
provisions. A recorded primary zoning label is not a parcel entitlement finding.
Current occupancy, businesses, title, design and finance are follow-up questions;
they do not silently exclude lots from broad discovery.

Use explicit BBL selections for deeper analysis. Browsing order is transparent
within groups, not a universal viability ranking. Optional FAR scenario screening
is a separate later experiment. Preserve completed packets and source snapshots.
