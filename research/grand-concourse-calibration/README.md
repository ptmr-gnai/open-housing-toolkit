# 425 Grand Concourse calibration

Known-case reconstruction with 2015 input documents and later reference evidence. Read report.md for findings and material protocol limitations. Original experiments are unchanged.

Run from the repository root:

    python research/grand-concourse-calibration/validate.py
    python -m unittest discover -s research/grand-concourse-calibration/tests -v

Python standard library; validation is offline. Cached text was produced with pdftotext -layout. Original official PDFs and retained web bodies are included. Sources retain dates, roles and historical-byte uncertainty. A current hosted packet is not a certified 2015 archive. Upstream document terms apply under the repository DATA-LICENSES.md.

The assessment is manually authored. The validator does not extract requirements, discover missing constraints, recompute design geometry or perform underwriting. No machine or human usefulness benchmark is claimed.
